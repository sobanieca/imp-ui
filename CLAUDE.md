## `prev/` folder

The `prev/` folder stores previous brainstorming ideas and experiments. **Always ignore it** during normal work — do not read, search, edit, or reference its contents unless I explicitly ask you to review specific code there.

## Code style

**Do not add comments to code.** Write self-explanatory code instead — use clear, descriptive names for functions, variables, and constants so the intent is obvious without comments. Reserve prose explanations for the docs (`docs/`) and ADRs (`adr/`), not inline in source files.
