imp-ui examples

Buildless ES modules — no compile step. Serve this folder and open an example.

render.js basics Live, annotated demos of argument dispatch, class/style/events, property-first props. Admin backoffice A small dashboard app: sidebar nav, stat cards, data table, invite form, toasts. Todo board Trello-style drag & drop board: moved cards keep their DOM and input text while their state bindings rebind to the new column. SSR islands (Hono) Server-rendered e-commerce page with three hydrated islands: cart widget, add-to-cart, and product reviews. Needs its own server — see the README.
