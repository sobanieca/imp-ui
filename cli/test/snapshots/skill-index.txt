imp skills - the usage manuals imp ships for the agent writing the code

imp is a buildless UI toolkit: your ES modules run in the browser exactly as written - no
compile step, no JSX, no bundler in development. Everything an app uses arrives through a
bare specifier imp resolves ('imp', 'imp/html', 'imp/state', ...), and the same imp binary
serves, tests, lints, formats and builds the project.

Read one in full - no flags, the text goes to stdout:

  imp skill state                  a subject listed below (several at once is fine)
  imp skill std/button             a standard component
  imp skill ./src/counter.js       a component of this project, by path to its module

WRITING AN APP
  imports            every bare specifier imp resolves, and what each one exports
  rendering          element factories, props objects, children, and mount
  components         custom elements with a build lifecycle: instance, styles, cleanup
  state              named reactive state shared down the tree and bound straight to the DOM
  http               the configured HTTP client a component owns, with retries and request state
  routing            client-side routes as one plain-data table, with lazily loaded sections
  std                the built-in component library: text, layout, forms, navigation and empty states
  theming            themes as plain token modules, applied at the entry point and swappable
  i18n               t() lookups, per-language messages, and the lang attribute that drives them
  logging            the built-in logger and the per-environment log level
  feature-flags      flag() gates a feature per environment and imp build folds the branch away
